MAD Blocker website settings

Sites with a special setting. Remove a site at any time to return it to normal blocking.

WebsiteSetting

No special settings yet.

Allow pop-ups tells Chrome to allow pop-ups on that site. Block more aggressively tells Chrome to block them and adds extra pop-under rules. Both need an optional permission that MAD Blocker asks for only when you first use them. To undo them, set the sites back to Default (or remove them) before you remove the permission.

Backup

Imported files are size-checked and validated. Anything unexpected is ignored.

Privacy

MAD Blocker keeps settings on this device only. It does not collect browsing history, passwords, cookies or form data, and it makes no network requests of its own.
