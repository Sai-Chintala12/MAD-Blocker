Sites with a special setting. Remove a site at any time to return it to normal blocking.

WebsiteSetting

No special settings yet.

Allow pop-ups tells Chrome to allow pop-ups on that site. Block more aggressively keeps Chrome's pop-up blocker on for that site (even if you allowed pop-ups everywhere) and adds extra pop-under rules. Pop-ups you open by clicking still work, so logins and payments are not broken. Both need an optional permission that MAD Blocker asks for only when you first use them. To undo them, set the sites back to Default (or remove them) before you remove the permission.

Protections

If one of these breaks a site, switch it off here instead of turning MAD Blocker off. Reload open pages afterwards.

Hide a specific element

If an ad slips through on a site, hide it yourself. Right-click the ad, choose Inspect, find its id or class and enter it like #top-banner or div.sponsored. The rule covers that site and its subdomains and uses the ad-space style you chose. Rules can only hide things, and you can remove them here at any time.

Privacy

MAD Blocker keeps settings on this device only. It does not collect browsing history, passwords, cookies or form data, and it makes no network requests of its own.
