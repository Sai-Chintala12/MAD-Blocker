# MAD Blocker privacy policy

_Last updated: 2026-10-11_

MAD Blocker is built to work without collecting anything about you.

## What MAD Blocker does not do

- It does **not** collect, store or transmit your browsing history.
- It does **not** collect passwords, cookies, form data or the content of web pages.
- It does **not** use analytics, advertising IDs or tracking of any kind.
- It does **not** send data to the developer or to any third party.
- It does **not** download or run remote code.
- It makes **no network requests of its own**.

## What is stored, and where

Your settings (on or off, ad-space style, and the list of websites with special settings) are stored in Chrome's local extension storage **on your device**. Uninstalling the extension deletes them. You can export, import or remove your site list on the settings page.

## How the permissions are used

- **Network request blocking (declarativeNetRequest):** Chrome applies MAD Blocker's rules inside the browser. MAD Blocker does not see or log the requests.
- **Active tab:** used only when you open the popup, to show and change the setting for the current website.
- **Pop-up settings (optional permission):** only if you choose "Allow pop-ups" or "Block more aggressively" for a site, MAD Blocker asks Chrome for permission to change Chrome's pop-up setting for those websites. It changes nothing else and sees no pop-up content.
- **Page access (content script):** MAD Blocker sets a marker on pages so ad containers can be hidden. It does not read or change page text, forms or cookies.

## Limits

MAD Blocker reduces ads and trackers. It is not antivirus software and does not replace browser updates or safe browsing habits.

## Changes and contact

If this policy changes, the date above changes and the change is listed in the repository history. Questions or security reports: use the Security tab of the project's GitHub repository.
